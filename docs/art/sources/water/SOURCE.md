# Sea and coast textures

`apps/client/public/themes/diorama/water/{caustics,sand}.webp` (a lagoon image was also generated and approved, then dropped when the water colour moved to a depth gradient) generated with the Gemini
image API ("Nano Banana") by `tools/sea-gen.mjs`, from text-only prompts (seamless stylized
lagoon water, grayscale caustics, beach sand), then made seamless by an offset cross-fade. The
owner-supplied reference screenshot guided only the mood and palette of the prompts; it was
never uploaded as an input, copied or traced, and is not shipped. No official Catan art used or
imitated. Generated content; no third-party license. Approved by the project owner 2026-11-06.
